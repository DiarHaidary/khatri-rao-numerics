# Archived R=480 sweep

These files preserve the former Figure 4 data and figures byte for byte
from commit 0efcb003a4a163d41dbcda7a5e19b4ac0b5c75e8. The previous source
is available at that commit. The current Figure 4 uses R=1536.

The new `rank_comparison_*` files use nested tail bases and identical
probes to compare R=480 and R=1536. That paired R=480 control is a
different fixed input from this historical R=480 run; the two should
not be expected to agree draw for draw.
